\section{Paper Explanation}
\label{sec:paper}

\subsection{Constructing the Conditional Target from a Flow}

Once we know that training with respect to the conditional vector field is equivalent to training with respect to the marginal vector field, the next step is explicitly constructing this conditional target. Instead of starting by designing a conditional probability path as in the original paper \cite{lipman2023flow}, we fix the interpolation flow $\phi_t$ first, which is geometrically more intuitive and generalizes better to arbitrary distributions. From $\phi_t$, we implicitly obtain the probability path via the push-forward operation, $p_t = [\phi_t]_* p_0$, and the target vector field simply by differentiating with respect to time.

Given a data point $z \sim q$, let $p_0 = \mathcal{N}(0, I)$ denote our initial noisy distribution and $p_1(\cdot \mid z) = \mathcal{N}(z, \sigma_{\min}^2 I)$ the conditional target distribution centered around $z$. Unless stated otherwise, $z$ is fixed and everything is conditioned on it.

A first approach could be the \emph{independent conditional coupling}: taking linear interpolants $\phi_t(x_0, x_1) = (1 - t) x_0 + t x_1$ between independent samples $X_0 \sim p_0$ and $X_1 \sim p_1(\cdot \mid z)$, whose instantaneous velocity is $x_1 - x_0$. However, $\phi_t(X_0, X_1)$ defines a stochastic interpolant rather than a deterministic flow: trajectories cross even for a fixed $z$ (Figure~\ref{fig:independent_coupling}), forcing the optimal field $u_t(x \mid z) = \mathbb{E}[X_1 - X_0 \mid \phi_t(X_0, X_1) = x]$ to average conflicting directions and inducing curved trajectories that require many ODE solver steps at inference.

\subsubsection{Straight Trajectories via Optimal Transport}

To obtain deterministic and injective trajectories conditionally on $z$, we pair each $x_0 \sim p_0$ (assumed absolutely continuous) with its deterministic Optimal Transport (OT) image $x_1 = T(x_0 \mid z)$, where $T: \mathcal{X} \to \mathcal{Y}$ (Brenier map) minimizes $\mathbb{E}_{x_0 \sim p_0}\|x_0 - T(x_0)\|^2$ subject to $p_1(\cdot \mid z) = [T(\cdot \mid z)]_* p_0$. Substituting $x_1 = T(x_0 \mid z)$ yields the deterministic conditional flow
\begin{equation}
    \phi_t(x_0 \mid z) = (1 - t) x_0 + t T(x_0 \mid z), \quad \forall t \in [0, 1].
\end{equation}
Because the interpolation is linear and $T$ is the OT map, $\phi_t(\cdot \mid z)$ is injective for all $t \in [0, 1)$ (see Appendix~\ref{injectivity} for the proof). Hence, conditional trajectories never cross, and the conditional vector field collapses to the exact particle velocity without averaging:
\begin{equation}
    u_t(x \mid z) = \frac{d}{dt}\phi_t(x_0 \mid z) = T(x_0 \mid z) - x_0, \quad x_0 = \phi_t^{-1}(x \mid z),
\end{equation}
inducing the probability path $p_t(\cdot \mid z) = [\phi_t(\cdot \mid z)]_* p_0$. The Conditional Flow Matching (CFM) loss becomes
\begin{multline}
    \mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t \sim \mathcal{U}(0,1), \, z \sim q, \, x_0 \sim p_0} \\
        \left[ \left\| v_\theta\big(t, \phi_t(x_0 \mid z)\big) - \big(T(x_0 \mid z) - x_0\big) \right\|^2 \right].
\end{multline}

At inference time, however, $z$ is unknown, so $v_\theta(t, x)$ converges to the \emph{marginal} optimal vector field $u_t(x) = \mathbb{E}_{(X_0, X_1) \sim \pi}[X_1 - X_0 \mid \phi_t(X_0, X_1) = x]$. As illustrated in Figure~\ref{fig:conditional_vs_marginal}, while $\phi_t(\cdot \mid z)$ prevents crossings for a fixed $z$, marginal paths across distinct targets $z^{(i)} \neq z^{(j)}$ still intersect whenever $(X_0, z)$ are paired independently---a limitation we address in Section~\ref{sec:beyond}.

\subsection{Closed-Form for Gaussian Distributions}

For isotropic Gaussians $p_0 = \mathcal{N}(0, I)$ and $p_1(\cdot \mid z) = \mathcal{N}(z, \sigma_{\min}^2 I)$, the OT map has the closed form $T(x_0 \mid z) = z + \sigma_{\min} x_0$, giving the affine conditional flow:
\begin{equation}
    \phi_t(x_0 \mid z) = \big(1 - (1 - \sigma_{\min})t\big) x_0 + t z.
\end{equation}
This way, starting from a flow and applying the push-forward change-of-variables formula (see Appendix~\ref{push_forward}), we recover the Gaussian conditional probability path proposed by Lipman et al.~\cite{lipman2023flow} (Figure~\ref{fig:conditional_gaussian_ot_1d}):
\begin{equation}
    p_t(x \mid z) = \mathcal{N}\Big(x \;\Big|\; t z, \; \big(1 - (1 - \sigma_{\min})t\big)^2 I_n\Big).
\end{equation}

Inverting $y = \phi_t(x_0 \mid z)$ gives $x_0 = \frac{y - tz}{1 - (1 - \sigma_{\min})t}$, and substituting into $\frac{d}{dt}\phi_t(x_0 \mid z) = z - (1 - \sigma_{\min})x_0$ yields the closed-form conditional vector field:
\begin{equation}
    u_t(y \mid z) = \frac{z - (1 - \sigma_{\min})y}{1 - (1 - \sigma_{\min})t},
\end{equation}
which simplifies the training objective to:
\begin{multline}
    \mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t \sim \mathcal{U}(0,1), \, z \sim q, \, x_0 \sim \mathcal{N}(0, I)} \\
        \Big[ \Big\| v_\theta\Big(t, \big(1 - (1 - \sigma_{\min})t\big)x_0 + tz\Big) - \big(z - (1 - \sigma_{\min})x_0\big) \Big\|^2 \Big].
\end{multline}

\subsection{Comparison with Diffusion-Based Probability Paths}

In \cite{lipman2023flow}, the authors reverse this order by prescribing a Gaussian path $p_t(x \mid z) = \mathcal{N}\big(x \mid \mu_t(z), \sigma_t(z)^2 I\big)$ first and inducing the flow $\phi_t(x_0 \mid z) = \mu_t(z) + \sigma_t(z) x_0$, yielding:
\begin{equation}
    u_t(x \mid z) = \frac{\sigma_t'(z)}{\sigma_t(z)}\big(x - \mu_t(z)\big) + \mu_t'(z).
\end{equation}
Reversing classical forward diffusion schedules ($s = 1 - t$) recovers:
\begin{itemize}
    \item \textbf{Variance Exploding (VE):} $\mu_t(z) = z$, $\sigma_t(z) = \sigma_{1 - t}$, giving $u_t(x \mid z) = -\frac{\sigma_{1 - t}'}{\sigma_{1 - t}} (x - z)$.
    \item \textbf{Variance Preserving (VP):} $\mu_t(z) = \alpha_{1 - t} z$, $\sigma_t(z) = \sqrt{1 - \alpha_{1 - t}^2}$ with $\alpha_s = e^{-\frac{1}{2} \int_0^s \beta(r)\,dr}$, giving $u_t(x \mid z) = -\frac{\alpha_{1-t}'}{1 - \alpha_{1-t}^2}(z - \alpha_{1-t} x)$.
\end{itemize}
Unlike our constant-velocity OT flow ($\mu_t(z) = tz$, $\sigma_t(z) = 1 - (1 - \sigma_{\min})t$), both diffusion paths exhibit nonlinear time scalings that curve trajectories and require finer numerical integration.
