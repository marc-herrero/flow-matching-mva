\subsection{How can we efficiently couple noise with data?}
\label{sec:preprocessing}

Although the CFM loss is computed over individual conditional paths $X_1 - X_0$, its minimizer is the marginal vector field $u_t(x) = \mathbb{E}_{(X_0, X_1)\sim\pi}[X_1 - X_0 \mid X_t = x]$, with $X_t = \phi_t(X_0, X_1)$. When $\pi$ is an independent coupling, trajectories heading toward different data points $z^{(i)} \neq z^{(j)}$ still intersect across the space, forcing $u_t(x)$ to average conflicting directions and producing curved marginal paths that require many ODE steps at inference. To straighten $u_t(x)$ and enable accurate generation with very few function evaluations (NFE), we must design a better coupling $\pi(x_0, x_1)$ between noise samples $x_0 \sim p_0 = \mathcal{N}(0, I_n)$ and smoothed targets $x_1 \sim p_1$, where $p_1(x_1) = \int \mathcal{N}(x_1 \mid z, \sigma_{\min}^2 I_n)\,q(z)\,dz$ (or $p_1 = \frac{1}{N}\sum_{i=1}^N \mathcal{N}(z^{(i)}, \sigma_{\min}^2 I_n)$ for a discrete dataset $\{z^{(i)}\}_{i=1}^N$).

\textbf{Independent coupling}

Here, noise samples $x_0 \sim p_0$ and data points $z \sim q$ are drawn independently from $p_0 \otimes q = p_0(x_0)\,q(z)$, and $x_0$ is then mapped via the conditional Brenier map $x_1 = T(x_0 \mid z) = z + \sigma_{\min} x_0$, inducing:
\begin{equation}
    \pi_{\text{ind}}(x_0, x_1) = \int \delta_{T(x_0 \mid z)}(x_1)\, p_0(x_0)\, q(z)\, dz.
\end{equation}
This ignores any geometric similarity between $p_0$ and $q$. Moreover, we can quantify the trajectory averaging in $u_t(x)$ via the irreducible conditional variance:
\begin{multline}
    \mathcal{C}(\pi) = \int_0^1 \\
    \mathbb{E}_{(X_0, X_1) \sim \pi} \left[ \left\| (X_1 - X_0) - u_t\big(\phi_t(X_0, X_1)\big) \right\|^2 \right] dt,
\end{multline}
which decomposes the objective as $\mathcal{L}_{\text{CFM}}(\theta) = \mathcal{L}_{\text{FM}}(\theta) + \mathcal{C}(\pi)$. Because $\mathcal{C}(\pi)$ does not depend on $\theta$, it sets a strict lower bound on $\mathcal{L}_{\text{CFM}}(\theta)$ even for an exact network. Under $\pi_{\text{ind}}$, frequent marginal crossings (Figure~\ref{fig:independent_coupling}) guarantee $\mathcal{C}(\pi_{\text{ind}}) > 0$, producing noisier gradients and curved trajectories that require many solver steps at inference.

\textbf{Semi-discrete OT coupling}

Since computing an exact OT map between $p_0$ and the intractable marginal $p_1$ is infeasible, we sample $N$ data points and formulate a global \textbf{semi-discrete OT} problem \cite{peyre2019computational} coupling the continuous source $\alpha = p_0$ to the empirical target $\beta = \frac{1}{N}\sum_{i=1}^N \delta_{z^{(i)}}$. Following the dual derivation in Appendix~\ref{Laguerre cells}, the optimal dual potentials $v^* = (v_1^*, \dots, v_N^*)$ partition the noise space $\mathcal{X}$ into $N$ polyhedral \textbf{Laguerre cells}:
\begin{multline}
    V_j(v^*) = \bigl\{ x_0 \in \mathcal{X} \\
        \;\big|\; \|x_0 - z^{(j)}\|^2 - v_j^* \le \|x_0 - z^{(k)}\|^2 - v_k^*, \;\; \forall k \neq j \bigr\},
\end{multline}
where each cell $V_j$ has the noise points associated to $z_j$, and carries probability mass $\frac{1}{N}$ at optimality (Figure~\ref{fig:laguerre_cells_real}).

During training, we sample $x_0 \sim p_0$, identify its cell $V_i$, and draw $x_1 = z^{(i)} + \sigma_{\min}\epsilon$ with $\epsilon \sim \mathcal{N}(0, I_n)$ 


\textit{(since $p_0(\cdot \mid z^{(i)}) = N p_0(\cdot)\mathbf{1}_{V_i}(\cdot)$ is truncated rather than full Gaussian, we cannot apply $\sigma_{\min}x_0 + z^{(i)}$). This remains a valid conditional construction because $\frac{1}{N}\sum_{i=1}^N p_0(\cdot \mid z^{(i)}) = p_0$.}

\paragraph{Positive aspects:} This is the globally optimal assignment. It eliminates trajectory crossings \textbf{both conditionally and marginally} as $\sigma_{\min} \to 0$, driving $\mathcal{C}(\pi_{\text{SD-OT}}) \to 0$ so that $u_t(x) = X_1 - X_0$ along straight paths (with only residual crossings near $t=1$), enabling fast few-step inference.

\paragraph{Negative aspects:} Optimizing $N$ dual variables and performing an $\mathcal{O}(N \cdot n)$ nearest-cell search at every step is costly for large $N$ and high dimensions. Furthermore, numerical dual optimization yields only approximate cell masses ($\approx 1/N$), biasing the data marginal, while the optimal field is discontinuous across Laguerre boundaries 

\textit{and leaves empty gaps in the marginal path (e.g., $(tz^{(1)}, tz^{(2)})$ in 1D for $N=2$), which a smooth neural network cannot represent exactly.}

\textbf{Mini-batch OT coupling}

As a scalable alternative when $N$ is large, we draw batches $\{x_0^{(i)}, x_1^{(i)}\}_{i=1}^{B}$ ($B \ll N$) and solve the discrete optimal assignment $\sigma^* \in S_B$ at the batch level \cite{tong2024improving, pooladian2023multisample}:
\begin{equation}
    \sigma^* = \operatorname*{arg\,min}_{\sigma \in S_B} \sum_{i=1}^B \left\| x_0^{(i)} - x_1^{(\sigma(i))} \right\|^2,
\end{equation}
using the Hungarian algorithm in $\mathcal{O}(B^3)$ time (or Sinkhorn in $\mathcal{O}(B^2)$ per iteration), and train on the matched pairs $(x_0^{(i)}, x_1^{(\sigma^*(i))})$ (Figure~\ref{fig:minibatch_ot_coupling}).

\paragraph{Positive aspects:} Accounting for batch-level geometry lowers regression target variance, reduces gradient noise, and yields much straighter flows than independent coupling. Moreover, it is done without precomputing global potentials, so it is more time efficient.

\paragraph{Negative aspects:} Enforcing a one-to-one permutation within each batch deviates from the global OT plan: if multiple batch noise samples fall into the same global Laguerre cell, mini-batch OT forces them toward distinct data points, reintroducing some crossings across batches. This approximation error shrinks as $B$ increases (at higher per-step cost) and reduces to independent coupling when $B=1$.
